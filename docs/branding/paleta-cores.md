# Paleta de Cores

## Visão Geral

Este documento define as diretrizes de cores da **Automind**, empresa fictícia especializada em **Agentes de IA Personalizados para Empresas**. Seu objetivo é garantir consistência visual e padronização durante o desenvolvimento da Landing Page.

A identidade da Automind foi concebida para transmitir **confiança, inovação, eficiência e profissionalismo**, posicionando a marca como uma empresa de tecnologia premium focada em resultados para negócios.

---

# Paleta de Cores

A paleta foi escolhida para criar uma identidade moderna e sofisticada, inspirada em empresas SaaS e de Inteligência Artificial, mantendo excelente contraste e legibilidade.

| Identificação           | Elemento      | HEX       | Uso                                         |
| ----------------------- | ------------- | --------- | ------------------------------------------- |
| `--color-midnight-navy` | Midnight Navy | `#0B1120` | Background principal da página              |
| `--color-slate`         | Slate         | `#111827` | Superfícies, cards e áreas secundárias      |
| `--color-slate-light`   | Slate Light   | `#334155` | Bordas e divisores                          |
| `--color-white`         | White         | `#F8FAFC` | Textos principais e elementos de destaque   |
| `--color-gray`          | Gray          | `#CBD5E1` | Textos secundários e descrições             |
| `--color-electric-blue` | Electric Blue | `#2563EB` | Cor primária, destaques e elementos de ação |
| `--color-cyan`          | Cyan          | `#06B6D4` | Cor secundária e elementos de destaque      |
| `--color-emerald`       | Emerald       | `#10B981` | CTAs principais                             |
| `--color-emerald-dark`  | Emerald Dark  | `#059669` | Estado de hover dos CTAs                    |

> **Observação:** As identificações acima devem corresponder às variáveis ou referências utilizadas na implementação do projeto.

## Gradientes

### Gradiente do Hero

**Cores:** Electric Blue → Cyan

```css
#2563EB → #06B6D4
```

**Utilizado em:**

- Hero;
- elementos visuais de destaque relacionados ao Hero.

### Gradiente de Elementos de Destaque

**Cores:** Cyan → Purple

```css
#06B6D4 → #8B5CF6
```

**Utilizado em:**

- elementos de destaque;
- elementos decorativos da interface.

### Glow

```css
rgba(37,99,235,.25)
```

**Utilizado em:**

- efeitos de brilho;
- elementos decorativos associados aos destaques visuais.
