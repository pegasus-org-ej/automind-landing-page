# Tipografia

## Visão Geral

A tipografia foi definida priorizando legibilidade, profissionalismo e uma identidade moderna voltada para produtos digitais.

---

# Fontes Utilizadas

| Identificação             | Fonte         | Utilização                       |
| ------------------------- | ------------- | -------------------------------- |
| `fonte-titulo-principal`  | Space Grotesk | Títulos e elementos de destaque  |
| `fonte-titulo-secundaria` | Sora          | Subtítulos e títulos secundários |
| `fonte-texto`             | Inter         | Textos e elementos da interface  |

## Fonte para títulos

### Space Grotesk

**Utilização:**

- Hero;
- Headings (H1 e H2);
- Grandes chamadas;
- Destaques.

**Características:**

- Moderna;
- Geométrica;
- Tecnológica;
- Forte presença visual.

**Identificação:**

`fonte-titulo-principal`

## Fonte para subtítulos

### Sora

**Utilização:**

- H3;
- H4;
- Cards;
- Títulos secundários.

**Características:**

- Elegante;
- Excelente leitura;
- Complementa a Space Grotesk.

**Identificação:**

`fonte-titulo-secundaria`

## Fonte para textos

### Inter

**Utilização:**

- Parágrafos;
- Botões;
- Formulários;
- FAQ;
- Navegação.

**Características:**

- Alta legibilidade;
- Excelente para interfaces;
- Consistência em diferentes dispositivos.

**Identificação:**

`fonte-texto`

# Tamanho da Fonte

| Elemento                  | Identificação             | Tamanho  |
| ------------------------- | ------------------------- | -------- |
| H1                        | `fonte-tamanho-hero`      | 36–60 px |
| H2                        | `fonte-tamanho-titulo`    | 30–36 px |
| H3 e Botões               | `fonte-tamanho-subtitulo` | 18 px    |
| Texto                     | `fonte-tamanho-texto`     | 16 px    |
| Texto de cards e pequenos | `fonte-tamanho-texto-sm`  | 14 px    |

## Tamanhos Responsivos

| Elemento | Mobile | Desktop |
| -------- | ------ | ------- |
| H1       | 36px   | 60 px   |
| H2       | 30px   | 36 px   |
