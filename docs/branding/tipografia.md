# Tipografia

A tipografia foi definida priorizando legibilidade, profissionalismo e uma identidade moderna voltada para produtos digitais.

## Fonte para títulos

### Space Grotesk

Utilização:

* Hero
* Headings (H1 e H2)
* Grandes chamadas
* Destaques

Características:

* Moderna
* Geométrica
* Tecnológica
* Forte presença visual

---

## Fonte para subtítulos

### Sora

Utilização:

* H3
* H4
* Cards
* Títulos secundários

Características:

* Elegante
* Excelente leitura
* Complementa a Space Grotesk

## Fonte para textos

### Inter

Utilização:

* Parágrafos
* Botões
* Formulários
* FAQ
* Navegação

Características:

* Alta legibilidade
* Excelente para interfaces
* Consistência em diferentes dispositivos

---
